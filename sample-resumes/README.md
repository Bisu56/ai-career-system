# Sample Resumes

Test PDFs for trying out the resume analyzer. Each is crafted to match a
different career path, so you can verify the prediction, skill extraction, and
recommendations end to end.

| File | Expected career | Key skills |
|------|-----------------|------------|
| `data_analyst.pdf` | Data Analyst | python, sql, data analysis, excel |
| `frontend_developer.pdf` | Frontend Developer | javascript, react, html, css |
| `backend_developer.pdf` | Backend Developer | python, php, laravel, sql |
| `devops_engineer.pdf` | DevOps Engineer | docker, aws, linux, git |
| `fullstack_mixed.pdf` | Frontend/Full Stack | mix of front-end, back-end, ML |

## How to use

1. Log in to the app and open **Upload Resume**.
2. Choose one of these PDFs.
3. (Optional) Paste a job description to also get a match score.
4. Click **Upload & Analyze**.

To test job matching, paste a posting that overlaps with the resume's skills —
e.g. for `data_analyst.pdf`, try: *"Seeking a data analyst skilled in Python,
SQL and Excel for dashboarding and reporting."*
