# AGENTS.md

Guidelines for AI assistants (Copilot, Kiro, Cursor, etc.) working in this repository.

## Repository layout

```
frontend/          React 19 + Vite + Tailwind UI
backend/
  laravel-api/     Laravel 12 REST API (auth, storage, PDF extraction)
  ai-service/      FastAPI ML service (career prediction, skill extraction)
```

## Running the project

```bash
./setup.sh   # one-time install
./start.sh   # starts all three services
```

Services: frontend :5173, Laravel API :8000, AI service :8001.

## Running tests

```bash
# Laravel
cd backend/laravel-api && php artisan test

# AI service
cd backend/ai-service && ./venv/bin/python -m pytest
```

## Key conventions

- **AI service URL** is configured via `AI_SERVICE_URL` in `backend/laravel-api/.env` (default `http://127.0.0.1:8001`). Never hardcode it.
- **ML models** (`model.pkl`, `vectorizer.pkl`) are generated by `python train_model.py` inside `backend/ai-service/`. Re-run after any sklearn upgrade.
- **Password rules**: min 8 chars, 1 uppercase, 1 number, confirmed. Enforced in `AuthController`.
- **Rate limiting**: upload/analyze endpoints are limited to 10 requests/minute per user via the `resume-upload` throttle key.
- **File uploads**: 2 MB PDF cap enforced both client-side (ResumeUpload.jsx) and server-side (Laravel validation).

## What to avoid

- Do not hardcode service URLs or secrets; use `.env` variables.
- Do not commit `venv/`, `vendor/`, `node_modules/`, `*.sqlite`, or `.env`.
- Do not lower password validation rules below the current minimums.
- Do not remove rate limiting middleware from upload/analyze routes.
